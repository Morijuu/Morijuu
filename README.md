# Hi, I'm Pablo Morell (Morijuu)

Freelance Shopify developer building and operating e-commerce stores for clients and a drop-shipping team,
and a game-dev student. Since July 2026 most of my theme work runs through an **agentic assistant I built on
Claude Code**: it pulls the live theme, edits, validates, screenshots desktop and mobile, compares against the
reference, pushes to an unpublished theme and publishes only after I say so in the chat. What it learns from my
corrections is written to memory and, when a rule keeps being broken, wired into a hook that blocks the action.

**→ [ecom-autopilot-showcase](https://github.com/Morijuu/ecom-autopilot-showcase)** — the public version: orchestrator
prompt, 6 sub-agents, the evidence-backed process gates, representative scripts and a terminal demo.

What I work with: Shopify (Liquid, Online Store 2.0, CLI, Admin GraphQL), Node 22, Playwright, Claude Code
(agents, hooks, MCP), Discord bots, Unity / C# for games.
